@@ set-up-employees-and-logins | How to set up employees and their logins | Keep an employee directory with compliance details, and give employees a login for self-service.
## Add an employee

Open HR, choose to add an employee and fill in:

- personal details and a photo
- the designation (you can add your own)
- compliance details: Emirates ID, passport and **visa expiry**
- bank details, IBAN, **labour card number** and bank routing code

You can print a profile from the record.

## Create a login

From the employee's record, **create their login** by email invite or with a temporary password, or link a login that already exists. Vrodux checks your seat limit when you do.

## Self-service

An employee with a self-service login can see only their own profile, attendance, leave and payslips. They cannot see the staff directory or anyone's salary.

@@ attendance-and-office-timings | How to set office timings and track attendance | Define office hours and grace time, then mark attendance and see who is on time or late.
## Set the office timings

In HR settings, set the **start and end time**, **grace minutes**, **working days** and **time zone**. Times are stored in local time.

## Mark attendance

- HR can mark attendance for staff, with bulk shortcuts.
- Employees can **check in and out** themselves from My HR.

Each day is recorded as **on time** or **late**, and the number of minutes late is kept.

Today there is one workspace schedule; per-employee shift schedules are not available.

@@ leave-policies-and-balances | How to manage leave policies and balances | Edit the UAE-baseline leave policies and approve requests with live balances.
## Policies

Leave policies start with **UAE-baseline defaults** that you can edit to match your own rules.

## Requests

1. An employee requests leave from My HR.
2. A manager **approves** or **rejects** it. Requests can also be **cancelled**.

Approvers are notified.

## Balances

A balance is calculated live as **entitlement minus approved minus pending**. You can see it per employee and for all staff.

@@ run-payroll-with-finance-approval | How to run payroll with Finance approval | Create a payroll run, adjust allowances and deductions, and have Finance approve it before payment.
## The payroll flow

A run moves through **draft → processed → Finance-approved → paid**.

1. Create a payroll run for the period.
2. Add **allowances and deductions** per employee, using the bulk adjusters where you can.
3. Mark the run **processed**.
4. **Finance** reviews it. Finance can edit slips, then **approve** or **reject** with a reason.
5. When approved, the run can be **paid**.

Approval can post an **accrual journal entry** in Finance. A rejected run can be edited and reopened.

## Payslips

Payslip emails are tracked. Employees can open their own payslip in My HR and print or save it as a PDF from the browser.

@@ generate-the-wps-salary-file | How to generate the UAE WPS salary file | Prepare a WPS salary file (SIF) with validated IBANs, and see who is excluded and why.
Vrodux **generates** the file. It does not send it to your bank.

## Before the first file

1. In settings, enter your **employer ID** and **agent routing code**.
2. For each employee, make sure the **labour card number** and **IBAN** are filled in. IBANs are validated.

## Generate it

1. Open the approved payroll run.
2. Choose to generate the **WPS (SIF) file**.
3. Review the list of any employees who are **excluded** and the reason for each. Fix those records and generate again if needed.
4. Download the file. The filename follows the standard.

## Before you submit

Check the file against your bank or exchange house template before the first live submission, then submit it through them.
